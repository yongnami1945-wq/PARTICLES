# Particle Morphing Studio 실행 안내

## 일상적인 사용

- **START-APP.cmd**를 더블클릭하면 서버를 시작하고 기본 브라우저를 엽니다.
- 주소: **http://127.0.0.1:3137**
- **STOP-APP.cmd**를 더블클릭하면 이 앱의 서버만 종료합니다.
- **STATUS-APP.cmd**에서 서버 실행 상태를 확인할 수 있습니다.
- 시작 파일을 여러 번 실행해도 서버는 하나만 유지됩니다.
- 브라우저 창을 닫아도 서버는 계속 실행됩니다. 완전히 종료하려면 종료 파일을 실행하세요.
- PC를 재부팅하면 서버는 종료되므로 시작 파일을 다시 실행하세요.

실행 파일은 Windows 명령 파일(.cmd)입니다. 이 프로젝트 폴더 및 설치된 Node.js가 필요합니다. 파일만 다른 폴더로 옮기지 말고 바로가기를 만들어 사용하세요.

## 작업 보관

앱의 프리셋/작업 저장 기능은 브라우저 저장소를 사용합니다. 같은 브라우저 프로필과 위 주소를 유지하세요. localhost나 다른 포트로 접속하면 별도 저장소로 취급됩니다. 브라우저 데이터 삭제에 대비해 중요한 작업은 앱의 프리셋 JSON 내보내기로 따로 보관하세요.

## 코드 수정 후 갱신 또는 의존성 복구

작업을 저장한 후 **REBUILD-APP.cmd**를 실행하세요. 서버를 종료하고 잠금 파일(package-lock.json)에 기록된 버전으로 패키지를 설치한 뒤 TypeScript 검사와 빌드를 수행합니다. 성공하면 START-APP.cmd로 다시 실행하세요. 패키지 설치에는 인터넷이 필요합니다.

개발 중에는 `npm run dev`를 사용할 수 있지만, 평소에는 START-APP.cmd로 빌드된 버전을 실행하세요. 기존 개발 서버 설정은 모든 네트워크 인터페이스를 사용하므로 평소 실행용 서버와 다릅니다.

## 운영과 문제 해결

- 평소 실행용 서버는 **127.0.0.1**에만 연결되어 이 PC에서만 접속할 수 있습니다.
- 화면이 오래된 경우 새로고침하세요. 소스를 수정했다면 먼저 재빌드하세요.
- 3137 포트를 다른 프로그램이 사용하면 시작이 실패하며 안내가 표시됩니다. 다른 프로그램을 임의로 종료하지 않습니다.
- 로그: **.runtime/server.log**. 시작 시 5MB를 넘으면 이전 로그 한 개로 순환 보관합니다.
- `.runtime/server.json`은 현재 서버의 상태와 종료용 토큰을 담습니다. 외부에 공유할 필요가 없습니다.
- 시작 오류가 발생하면 로그 및 STATUS-APP.cmd를 확인하세요. 의존성 누락은 REBUILD-APP.cmd로 복구합니다.
- 3D 화면 성능은 GPU, 브라우저, 화면 해상도, 입자 수에 따라 달라집니다. 느리면 입자 수를 줄이고 BLOOM을 끄세요. 비활성/백그라운드 창에서는 브라우저가 FPS를 낮출 수 있습니다.
- 기본 파티클 편집 기능은 Gemini API 키 없이 실행됩니다. 외부 프리셋 URL 가져오기 등은 인터넷 연결 및 해당 사이트의 접근 허용 여부에 영향을 받습니다.
- 자동 시작/자동 재시작 Windows 서비스는 설치하지 않았습니다. 서버가 종료되면 START-APP.cmd로 다시 시작하세요.

## 점검 명령

프로젝트 폴더에서 다음을 실행할 수 있습니다.

```text
npm run lint
npm test
npm run build
npm run test:smoke
```

`test:smoke`는 앱 서버를 중지/재시작하며 완료 후 중지 상태로 둡니다. 편집 작업을 저장한 뒤 실행하세요. 시작 경쟁, 중복 실행, HTML/JS/CSS 제공, 소스/토큰 비공개, 비인증 종료 차단, 종료와 재시작, 포트 충돌 처리를 검사합니다.

## 이번 안정화 수정

- 사용자 형상을 복원할 때 배열 순번(0, 1, 2…)이 입자 수로 전달되던 오류를 수정했습니다. 저장/복원을 반복해도 요청한 입자 수를 유지하도록 회귀 테스트를 추가했습니다.
- 이전 오류로 축소 저장된 앱 생성 텍스트 형상은 저장된 표시 이름으로 글자와 줄바꿈을 재생성합니다. 원래의 개별 입자 위치/색상과 완전히 같지는 않습니다. 복구 전 작업은 브라우저 저장소의 `particle_morph_recovery_backup_시간값`에 보존합니다.
- 형상 교체 시 기존 GPU 지오메트리·재질·텍스처를 해제하도록 수정했습니다.
- 패키지 설치, TypeScript 검사, 빌드, 저장·복원 회귀 테스트 3개, 서버 운영 테스트 8개를 점검했습니다. 모든 내보내기 포맷·외부 사이트 연동·장시간 연속 부하를 검증한 것은 아닙니다.
